Request

GET

Stored only in this browser's localStorage, and only sent to this API itself -- never to any third party.

e.g. NDVI_mean, NDRE_mean, RVI_mean -- see GET /api/v1/farms/indices for the full list this deployment computes.

Leave blank for each index's latest reading, or pick a date from GET /api/v1/farms/{farm_id}/available-dates.

Leave both blank for full history. Both bounds are inclusive.

Off: only real satellite readings. On: also includes gap-filled dates -- each result is tagged satellite, interpolated, or provisional so you can decide what's good enough for your use case.
